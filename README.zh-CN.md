# 抖音精读

[English](README.md) | 简体中文

在电脑端抖音视频旁阅读带时间点的中文逐字稿，区分本期说话人，搜索原话、生成内容概览、解释选段、记录笔记，并把资料保存到自己选择的本机文件夹。

![抖音视频与抖音精读侧栏，逐字稿按时间显示说话人 1 和说话人 2](assets/douyin-digest-speaker-transcript.png)

<p align="center"><em>真实电脑端使用画面：视频、逐字稿与本期说话人同步呈现。</em></p>

这是基于 Zara Zhang 的 [YouTube Digest](https://github.com/zarazhangrui/youtube-digest) 衍生的独立开源项目。保留原项目 MIT 许可和版权说明；抖音适配、音轨转写、说话人呈现和资料管理由本项目独立维护。本项目与抖音官方无隶属关系。

## 主要能力

- 有可读字幕时直接使用；无字幕时可将当前公开视频的整期音轨提交给火山语音。
- 显示逐句时间点和“说话人 1 / 说话人 2”等本期声音分组，可为本期编号填写姓名。
- 点击时间点回听，搜索全文，跟随视频播放位置阅读。
- 使用 DeepSeek 生成概览、解释选中文字，并保存时间点笔记。
- 在“我的资料”中按标题或作者查找内容，将逐字稿、概览和笔记保存为 Markdown。
- 密钥、缓存和笔记保存在当前 Chrome 扩展本地存储，不经过本项目自建服务器。

## 安装

需要 Chrome 116 或更高版本。

1. 在 GitHub 下载源码 ZIP 并解压到一个准备长期保留的文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择包含 `manifest.json` 的项目文件夹。
4. 打开扩展设置，自己填写所需服务的 API Key 并保存。不要把 Key 发到聊天、截图、Issue 或源码里。
5. 打开一条公开抖音视频，点击页面上的“抖音精读”或扩展图标。

源码更新后，在扩展程序页点击“抖音精读”卡片的重新加载按钮，再刷新抖音页面。不要为了更新先卸载扩展；卸载可能清除浏览器中的设置和资料。

## 服务设置

- 火山语音：用于没有字幕时的整期音轨转写、逐句时间点和本期说话人编号。请选择自己账号实际开通的录音识别版本；服务可能收费。
- DeepSeek：用于内容概览和选段解释。
- Supadata：保留为可选逐字稿服务；具体可用范围和费用由服务商决定。

程序只提供调用入口，不附带任何 API 额度。外部服务会按各自条款处理提交的视频地址、音轨或文本。

## 说话人结果怎么理解

“说话人 1 / 2”是语音服务对当前这一期声音的分组，不是人脸识别，也不是跨视频固定身份。你可以在当前视频中把编号改成姓名；遇到多人重叠、音质差或声音相近时仍可能分错，重要引用应点击时间点回听抽检。

## 我的资料与本机文件

侧栏顶部点击“我的资料”，或从设置里的“资料与本地保存”进入。第一次选择一个资料根文件夹，再点击“保存全部资料”或单篇“保存到本机”，内容会进入：

```text
你选择的文件夹/
└── 抖音/
    └── 视频标题 [视频编号]/
        ├── 逐字稿.md
        ├── 内容概览.md
        └── 我的笔记.md
```

相同内容不会重复写入；内容变化会保存编号副本，不覆盖旧文件。浏览器中的“我的资料”与本机文件不是自动同步关系，只有点击保存后才会写入文件夹。

## 当前范围

支持电脑端公开抖音视频详情页，以及能确定当前视频编号的搜索或作者弹层。不承诺支持首页连续刷、直播、私密或受限视频、移动端与其他短视频平台。

长视频处理需要读取和准备完整音轨，时间取决于视频长度、网络和语音服务。关闭或重新加载浏览器可能中断正在处理的任务。失败时保留页面提示和视频链接；不要连续重复提交不确定的任务。
